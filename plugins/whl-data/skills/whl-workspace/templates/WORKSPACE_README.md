# WHL workspace

โฟลเดอร์งานมาตรฐานของทีม - ทุกคนใช้โครงเดียวกัน เปิด Claude Code ที่โฟลเดอร์นี้

| โฟลเดอร์ | ใส่อะไร |
|---|---|
| `projects/<ลูกค้า>-<งาน>/01_input` | ไฟล์ที่ได้รับ (brief, master จากลูกค้า) |
| `projects/<ลูกค้า>-<งาน>/02_data` | ข้อมูลดิบที่ดึงมา - ห้ามแก้มือ |
| `projects/<ลูกค้า>-<งาน>/03_output` | ไฟล์ส่งงาน |
| `projects/<ลูกค้า>-<งาน>/scripts` | สคริปต์ / Apps Script |
| `projects/<ลูกค้า>-<งาน>/NOTES.md` | ข้อมูลอ้างอิงของงาน |
| `templates/` | แม่แบบที่ใช้ร่วมกัน |
| `_scratch/` | ไฟล์ชั่วคราว ลบได้ |

ชื่อไฟล์: `<ลูกค้า>_<เนื้อหา>_<YYYY-MM-DD>.xlsx` / อย่าเก็บโฟลเดอร์นี้ใน OneDrive หรือ Drive ที่แชร์ (มีข้อมูลลูกค้าและพนักงาน)
